## 什么是BEM国际命名规范
- .page 页面(div)
    意味：开启一个区块block
- 分为上下两部分
    .page__hd：头部(div)
    .page__bd：主体(div)
## BEM 的优势是什么？
- 国际规范,大家都会遵守
- 结构清晰，搭建盒模型方便
    规则：
    - 有一个区块要表达 用block
    - 有几个元素要表达 用elements
    - Modifier 修饰符
        
- 可读性好
- 解决了写页面命名难的问题
    用最简单的英文单词 最好和结构相关的单词
    如： .page
            .page__hd
            .page__title
## css规则
- css reset 重置样式
    去掉页面默认的内外边距
        一般不用*，一般是列出要匹配的所有元素
