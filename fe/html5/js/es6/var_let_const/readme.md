## var let const
早期的js 使用var 声明变量 没有常量，用代码规范约束
var PI = 3.1415926
- var 只作用域只被函数限制
- let const 都会被块级作用域限制（{}）


## for + setTimeout（典型面试易错题）
for(var i = 0 ; i < 10 ; i++){
    log(i)
    setTimeout( log(i), 1000)
}
如果定义的变量是var 
    步骤是：
    i=0 回调函数1 
    i =1回调函数2
    .......
    当主线程结束即循环结束调用回调函数由于var是全局作用域，所有最后回调函数里面都是10
    即循环里面var 就生成一次

如果定义的变量是let
      当主线程结束即循环结束调用回调函数由于let是有块级作用域，每次循环都会生成新的作用域
      所以最会回调的时候都会捕获到当前的let
      即循环里面let 每次都会生成

const 声明时就要赋值，let声明和赋值可以分开
简单数据类型不可以改变值
复杂数据类型值可以改变，类型不可以改变
