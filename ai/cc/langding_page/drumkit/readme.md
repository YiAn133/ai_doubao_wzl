## Plan mode 规划模式
/plan
降低了prompt门槛
通过询问一些问题,帮助我们组织Prompt 让我们完成需求

## 指令
/ 开头 表示指令 这是cc的指令
/plan 这个指令是规划模式
/init 初始化
