# RAG 实战
RAG是什么？有什么用？
RAG是信息检索增强，就是让AI不单单依靠预训练得到的知识回答用户的问题，而是去调用本地的知识库，返回给大模型，大模型再结合上下文给出答案
可以解决 1.信息过时  2.避免AI编制的内容 3.能接入私有的数据  4.能精准访问数据（设置AI访问的数据在哪里，它就只会根据那个知识库做出反应）
