# 向量数据库

## Milvus
文档向量化放到向量数据库，每次查询根据向量化的query去数据库做相似度匹配，查出相关文档放到Prompt中
给大模型，让大模型生成答案

- 从之前的内存存储到向量数据库
Milvus是一款开源的向量数据库，转为处理海量高维向量数据而设计。

像web应用会把数据存在mysql，Sqlite，psql，基于对数据的增删改查实现各种业务功能。
根据id或者关键词（like）去关联查询一些列表的数据

Agent 会把知识，记忆放在Milvus数据库中，对知识，记忆语义检索，增删改等各种功能。

## AI 日记本
- 日记的增删改查 非AI功能 结构化数据 一般用Mysql
- 但是当查询类似 心情比较的日记
    一般是将内容向量化存储到milvus中 AI功能
