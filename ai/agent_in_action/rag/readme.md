# RAG

## llm的幻觉
大模型知道的知识，取决于训练时给它的**数据集**.
如果你问它最近发生的事情，或者你企业内部的私有的文档，llm是不知道的。
但是它不会说自己不知道，而是胡乱回答，也就是所谓的幻觉。

## 如何解决大模型的幻觉？



用户要查询的内容，我们先去内部**知识库**里面查一下，把它放到Prompt里再给大模型。

大模型通过这些**知识库**里文档知道了背景知识，就可以回答问题。

RAG
Retrieval 检索 - Augmented增强  Generation生成

去知识库里面**检索**用户问知识的相关文档片段（分片，按页，按段落分成一段段有自然语义的段落）（embedding），作为背景知识加到Prompt里**增强**它，让大模型根据这些生成**回答**

- 用户问了一个问题，你怎么把相关的文档片段查出来?

- 关键词搜索？
    文本匹配，不太行
- 向量 vector 语义查询就可以

RAG 一般结合向量化来做，比关键词搜索更牛

用到专门的模型，叫嵌入模型(Embedding Model)
可以打知识库里的文本，图片，pdf，语言，向量化后，都可以语义搜索。

## 俩个突破
    - 文档怎么切分？
    - 向量 怎么把相关文档查出来？
    - 向量数据库？

在原始Prompt给到大模型之前，查询知识库，把相关的文档作为背景知识加入到Prompt里，再让大模型回答，这就是RAG。

RAG 要实现语义查询，需要基于向量来做，查询知识库，把相关文档作为背景知识加入到Prompt，再让大模型回答，这就是RAG。
