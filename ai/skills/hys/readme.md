# Skills  会议室
会议纪要的自动化 Skills
## skill - creator
创建一个会议纪要skill，它拥有会议小秘书的专项技能，根据会议纪要文件或录音，生成会议纪要，将
重复的（什么主题，什么人员参加....），繁琐的工作自动化

### skill - creator
固定的结构和模式
- 文件夹
    - SKILL.md
    把这个工作如何做的，用skill.md记录下来

- skill - creator
    会有自己封装skill的需求，当我们频繁重复的时候
Anthorpic 官方推出的 skill - creator 标准化，简化skill的封装的。
