# Workflow & Agent 有什么区别？

- Workflow 是程序员编程好的
- Agent 是llm动态自主运行的

## AI Workflow 工作流
将智能体融入稳定固定的工作流中，适合为流程性工作提效，自动化。
- workFlow 本质是一套预定义的流程，可以想象成一套生产的流水线。每一步都有明确的输入和输出，每个节点的逻辑
都是固定的。

langchain是用于快速搭建工作流的开发框架，灵活构建各类智能任务链路。

## Agent 智能体
和workflow 逻辑完全不一样，它不是走在一条预设的轨道，而是站在一个开发是空间，自己去探索怎么去做
一个 Agent 往往具备三个大的核心能力

第一：感知环境
通过输入文本，图像，数据来理解任务。有哪些工具可以调用，当前情况如何，如何分步骤，如何规划。
第二个：规划路径
不是预先定义好的，而是动态去生成任务链。
第三个：执行行动
去调用工具，完全子任务，不断去调整。

## 举例
你让Agent去规划旅行，它可能不会按照你预期一模一样，这就是Agent的关键区别，它有自主性和适应性。

所以从产业角度上来说，workFlow更适合一些流程化，重复性的任务
如审批流程，客服AI等
Agent 更适合动态的一个角色。比如：复杂搜索，策略规划

未来我们的AI工程中会几何Agent和WordFlow 的双重能力。
底层是workflow 去提供稳定性和可控性，上层是Agent 提供灵活性和智能型。

workflow 是骨架，Agent是Workflow的大脑
